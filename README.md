# ADCarousel | 简易广告轮播工具

上海企通数字科技有限公司 -  开源项目 - ADCarousel | 简易广告轮播工具

简单的广告+时间显示的轮播工具

### 功能描述：

任意上传背景图片，选择文字颜色和大小以及显示位置(x,y)坐标，文字默认：当前日期时间 格式:yyyy.MM.dd HH:mm:ss

### VS Code / GitHub Copilot 常见报错说明

如果你在 VS Code 里看到类似下面的日志：

`PermissiveAuthRequiredError: Permissive authentication is required`

这通常**不是你的项目代码报错**，而是 **GitHub Copilot Chat / Agent 在获取组织信息或可用模型列表时，发现当前 GitHub 登录授权不满足“更宽松的认证权限”要求**，因此拒绝了这次请求。

常见原因：

- 当前登录的是企业或组织账号，组织策略限制了 Copilot 的某些资源访问
- VS Code 中的 GitHub / Copilot 登录状态过期，或者授权信息不完整
- Copilot Chat 扩展版本较旧，和当前认证流程不完全兼容

一般可以按下面顺序排查：

1. 在 VS Code 中退出 GitHub 与 Copilot 账号后重新登录
2. 更新 GitHub Copilot 与 GitHub Copilot Chat 扩展到最新版本
3. 打开 GitHub 账号的授权页面，确认 VS Code / Copilot 相关授权没有失效
4. 如果你使用的是公司或组织账号，联系组织管理员确认是否允许 Copilot 访问组织资源或模型列表

如果只有这条日志，但 Copilot 基本对话和补全功能仍然可用，通常说明是**组织资源读取失败**，不一定会影响你当前项目的正常开发。
